## Unverified

1. Locate on DAT / OSTAT compares the typed text with the field's text form. The web uses dd.mm.yyyy and FloatToStr with `,` as the decimal separator, as the other ported modules do. The Windows regional settings of the Delphi clients are not in the repo.
2. `SBOP.Get_Date` is assumed to return a date without a time part. The pickers bind `.Date`, so the time part would be dropped anyway.
3. Grid captions in the .dfm are Azl Sans Serif code points (Cyrillic on screen, e.g. 'Тарих' = Tarix). The web shows the Azerbaijani text.
