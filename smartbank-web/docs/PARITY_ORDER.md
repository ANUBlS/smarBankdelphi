## Unverified

1. ReserveAccs filters on `archost.datdate = (select TEK_DAT from sysdat)`, `pok_ostat > 0` and the 'Reserv' zone groups; the mock data is made up to show this, not taken from a real DB.
2. The NAME DBEdits are editable in Delphi, but the detail selects have no ROWID, so a DOA Post of an edited name would fail. The web shows them read-only.
3. Captions are Azl Sans Serif code points (Cyrillic on screen). The web shows the Azerbaijani text; 'iqdisadçısı' in Label8 is shown as 'iqtisadçısı'.
