## Differences from the Turan copy (cards_azericard_turan_version), as they affect the port
- **Menus.** cards_azericard has *Exchange file* (E1), *RbsTax* (T1) and *RbsDoFile* (R1 → Tdorbsfile, no right check). Turan has R1 'RBS DO' → Trbsdo
  with right card_rbsdo instead. Online Cards has no `configuration.myswift <> 'TURAAZ22'` gate. Sazlama does not open `sazlamalar`.
  Units only in cards_azericard: cfile_addi, excsett, card_Exchange_file, Rbsdofiles, rbsstate, card_states, Taxrbs, Taxfilessettings.
  Units only in Turan: Unit28, Reportpayment, rbsdofile, rbsdostatement, rbsdoreport, **UFX71** (the UFX web service), Unit30,
  Cardsdeleted_report, newcardeditfrm. **Production cards has no UFX71** (card_ufx.pas for Karta Mədaxil is still there).
- **Clients SQL** (Unit18.dfm:3247) has 20 lines and selects `s.multival`. There is no SQL[25] slot.
- **FormActivate :271** has no CARD_FIL_VIEW branch: every user with card_clients sees all filials (Turan limits users without CARD_FIL_VIEW to their own filial).
- **Grid.** dbGrid2 shows MULTIACC (3rd column) and has no VERI column.
- **Panel4 search.** cards_azericard keeps the TDataSet SearchRecord. Turan replaced it on 16.06.2020 with a server-side search through `:pSearch` / SQL[25].
  The web already followed the TDataSet version.
- **Edit (ToolButton3Click :228)** loads cliencards / CARDOPERATION by `Clients.multi_acc` (Turan: RBSNUMBER), then sets Edit1 = 'EDIT' and shows the form.
- **Excel** uses its own dataset `cliexcel` (WHERE s.multiacc is null ORDER BY s.rbsnumber), with only the Panel5 filter. Turan exports the grid's dataset.
- **Unit18.dfm:** 22 datasets differ in SQL; 16 exist only in cards_azericard and 21 only in Turan. Unitclient2 (the add / edit form) differs in about 600 .pas lines.
