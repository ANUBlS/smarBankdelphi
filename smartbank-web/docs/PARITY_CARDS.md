# Cards (Packages/Cards_New) – parity notes

**Source variant.** `Packages/Cards_New` holds five copies of `CARDS.dpr`. All of them register the same CoClass MAINFORM
`{D5432094-E84C-4EAE-80FC-D02224B17B93}`. The port follows **`cards_azericard_turan_version`**, because it is the Turan build
(it has `UFX71.pas`, the same UFX service as AZIPS, plus `Reportpayment`, `rbsdofile/statement/report`, `Unit28`, `Unit30`,
`Cardsdeleted_report` and `newcardeditfrm`). `cards_azericard` lacks these and has `Taxrbs`, `Rbsdofiles`, `card_states`
and `excsett` instead. **Unverified:** which copy your production OCX was built from. If it was a different one, say so before the next steps.
The user confirmed `Cards_New`, not `Cards_New_19082013`. `web/modules.json` used to point at `cards_azericard - Copy` and now names the Turan copy.

API `api/app/cards.py` (`/api/cards`), filter engine `api/app/tdataset_filter.py`, verbatim SQL `api/app/cards_sql.py`
(127 datasets of Unit18.dfm, generated by `tools/gen_cards_sql.py`), mock `api/app/db/mock_cards.py` + `fixtures/cards.json`,
