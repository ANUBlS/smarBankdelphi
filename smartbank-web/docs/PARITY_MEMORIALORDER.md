## Unverified

1. DOA builds the update / insert text itself (bind names `:BALANCE` / `:doa__rowid`); the web uses the same statements with its own bind names. LockingMode lmCheckImmediate (DOA locks the row with `select … for update nowait` when editing starts and checks it was not changed) is not reproduced, as in the other ported DBNavigator forms.
2. After an insert the web reloads the Memorial list (rows in the server's order); Delphi keeps the new row where it was inserted until Refresh.
3. Whether the TSearchCombo DataSource links (to MOrdDataMod, created in OnCreate) are resolved before CreateWnd in the production build. The web assumes the combos are filled.
4. Captions in the .dfm are Azl Sans Serif code points (Cyrillic on screen). The web shows the Azerbaijani text (e.g. 'Филтердян истсфадя етмяк' → 'Filterdən istifadə etmək', typo fixed).
