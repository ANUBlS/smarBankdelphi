Подключение ActiveX  модуля к  программе Smart Bank

  1) Подключаемый ActiveX модуль должен быть в папке \Smart-Bank\Bin\

  2) Модуль должен быть зарагестрирован в системе (regsvr32 или др.)


 3)Меняем SmartBank.ini добавив информацию об подключаемом ActiveX

    a) Записываем Class GUID который находится в  имя_модуля_tlb : guid  константы с именем 
       class_имя_модуля
  
        н.р   CLASS_SomeProject: TGUID = '{344076A6-BD3C-4086-88CA-904D1F83DE1F}';

   b)Инкрементируем в секции [PluginManager\Packages] параметр Count

   c)Добавляем новый элемент
    
    ;имя_модуля
    Item23=axinplace:{8407FDE6-3D6C-4086-88CA-904D1F83DE1F},overlapped

   d)Меням дерево добавив туда новый элемент 

    [Tree\Sections\Item0\Item11\Item1]
     Caption=Это Имя отражается в дереве
     Action=#23      - число должно совпадать с числом в Item
     Count=0

   с)увеличиваем число секций Count в предедущей секции в данном случае [Tree\Sections\Item0\Item11]
